# DeskReview: UI, Телемост, продукт (2026-05-19)

> **Код по этому документу пока не меняем** — только план. Репозиторий может называться `3d_viewer`; продукт для компании и пользователей — **DeskReview**.

## Название и использование

- **DeskReview** — рабочее место согласования PDF + 3D (desk + review).
- Внутри компании (NordFox и др.) — то же имя, текущий функционал.
- Удалить из шапки заголовок **«3D Viewer»** → бренд **DeskReview** (логотип/текст).
- **AnyDesk / удалённый рабочий стол** — **не** в плане MVP; для «помощи без установки» достаточно Телемоста + демонстрации экрана в звонке + совместного просмотра (этап 8).

## Верхнее меню (`ViewerToolbar` → реорганизация)

Убрать с панели инструментов в открытую:
- переключатель **Инженерный / Производство (QR)**;
- кнопки макета **2D / 3D / Совмещ. / Лог**;
- отдельную кнопку **«Отчёт»**.

Заменить выпадающими меню:

| Меню | Содержимое |
|------|------------|
| **Файл** | Открыть PDF; открыть 3D; сохранить PDF; сохранить PDF как; сохранить 3D (GLB / замечания JSON); сохранить 3D как; разделитель; проект сборки (открыть/сохранить); позже — сохранить PDF с замечаниями (3c) |
| **Режим** | Инженерный / Производство (QR); макет: только 2D / только 3D / совмещённый |
| **Логи** | Показать панель логов (`viewMode = log`) |
| **Скриншот-отчёт** | Экспорт скриншот-отчёта в PDF; отправить отчёт по почте; отправить отчёт в чат |
| **Телемост** | См. ниже |

### Горячие клавиши

- **Ctrl+S** — сохранить активный документ: если фокус/контекст PDF → PDF (или PDF с замечаниями после 3c); если 3D → GLB и/или JSON замечаний. Модалка: «Сохранено: путь/имя файла».
- **Ctrl+Z** — отмена последнего действия в **активном** виджете (PDF-разметка или 3D-разметка/измерения), отдельные undo-стеки.

## Телемост (этап 9c)

> Сейчас в коде: одна комната на проект, API `GET /api/projects/{id}/telemost`, вкладка «Телемост» в правой колонке, ссылка в новую вкладку. Встроить звонок **внутрь** страницы без перехода на `telemost.yandex.ru` API Яндекса **не позволяет** — минимум один клик → открытие `join_url`.

**Меню «Телемост» (после «Скриншот-отчёт»):**

| Пункт | Поведение |
|-------|-----------|
| **Присоединиться к звонку проекта** | `GET .../telemost` → если комнаты нет — **создать** → сразу `window.open(joinUrl)`. **Не** создавать новую комнату на каждый клик — одна главная на проект. |
| **Создать отдельную встречу…** | Новая конференция API → запись в `project_telemost_rooms` → для подгрупп (несколько групп одновременно). |
| **Активные встречи** | Список комнат проекта: Войти / Пригласить (в чат + WS + буфер), без пересылки в ТГ/почту вручную. |

**«Все одним нажатием» для участников проекта:**

- Инициатор жмёт «Присоединиться» → WS-событие `telemost.join` → у онлайн в DeskReview баннер «Начат звонок» + **[Войти]** (тот же URL).
- Автосообщение в чат канала со ссылкой (запасной путь).

Требования: вход в коллаб, выбран проект, `YANDEX_TELEMOST_OAUTH` на сервере.

## Левая колонка 3D (`Viewer3D`) — табы

Сейчас: боковая полоса «Модели»; плавающие «Сборка» и «Измерения» поверх канваса.

| Таб | Содержимое | Связь с кнопками в шапке 3D |
|-----|------------|------------------------------|
| **Модели** | Список карточек/иконок, метрики, + | как сейчас |
| **Сборка** | Весь UI `viewer-assembly-float` | кнопка «Сборка» → таб «Сборка», убрать плавающую панель с канваса |
| **Измерения** | Панель измерений (журнал, типы) | кнопка «Измерение» → таб «Измерения», убрать float с канваса |
| **Замечания** | Дерево 3d (этап 3d), режим работы | отдельный режим |

**Таб «Замечания» (3D):**

- Дерево комментариев; клик → живая сцена + `viewState` + оверлей + якорь (см. [session-2026-05-19-3d-remarks-edrawings.md](session-2026-05-19-3d-remarks-edrawings.md)).
- Блок вставки изображения:
  - поле пути (файл / URL);
  - **Открыть** (предпросмотр);
  - **Добавить** — вставка на `screenLayer` в **текущем** ракурсе (отдельная команда).

## Левая колонка PDF (`PdfViewer`) — табы

| Таб | Содержимое |
|-----|------------|
| **Документ** | PDF, миниатюры страниц, зум |
| **Замечания** | Дерево по страницам (этап 3c) |

**Дерево PDF:**

- Группировка: **«Стр. N»** → вложенные замечания на листе (не засорять общее дерево).
- Название узла замечания включает **номер страницы**.
- Клик → страница + область + зум + оверлей.
- Тот же блок путь / Открыть / Добавить для картинок на чертеже.

## Workspace: панели Диска и чата

- Диск: сворачивание **влево**, ресайз сплиттером (160–480 px).
- Чат: сворачивание **вправо**, ресайз (260–720 px).
- *В коде частично:* `diskPanelCollapsed` / `chatPanelCollapsed` в `App.vue` — **доработать UI** (кнопки свернуть/развернуть, `effectiveRightPanelWidth` в шаблоне). Известная проблема: `chatPanelCollapsed=1` в localStorage без кнопки разворота — чат «не открывается».
