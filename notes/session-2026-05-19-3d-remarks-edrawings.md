# 3D: замечания по образцу eDrawings (этап 3d, 2026-05-19)

## Цель

Замечания на **3D-модели** (GLB/сборка) с тем же сценарием согласования, что в eDrawings: **дерево комментариев**, клик → **живая сцена** в нужном ракурсе + разметка и картинки на слое. Модель **не переписываем** — рядом JSON и папка assets (аналог `*.markup`).

Ссылки SOLIDWORKS:
- [Markup Overview](http://edrawings.helpmax.net/en/welcome-to-edrawings-help/edrawings-professional/markup/markup-overview/) — комментарий помнит **model state** при создании.
- [Markup Files](https://help.solidworks.com/2024/english/eDrawings/c_Markup_Files.htm) — sidecar только с замечаниями.
- [Markup Tools](https://help.solidworks.com/2020/English/eDrawings/c_Markup_Tools.htm) — **Insert Image**, фигуры, текст.

## Режим просмотра: живая 3D-сцена

При выборе замечания в дереве:

1. Восстановить `viewState` (position, target, up, fov; при необходимости скрытые `modelId`, сечение).
2. Показать `screenLayer` (стрелки, текст, рамки, вставленные изображения) **поверх живого канваса**.
3. Показать **якорь 3D** (маркер на грани), если задан.
4. **Не** использовать snapshot как подложку для навигации.

Snapshot (`thumb.png`) — опционально при создании: миниатюра в дереве, вложение в чат, отчёт.

## Два типа привязки

### `anchor3d` (мировая, постоянная)

- `modelId` + точка в локальных координатах детали + нормаль грани.
- Позже: `faceIndex` + барицентрические координаты на треугольнике.
- Маркер/флажок в сцене **не съезжает** при орбите.

### `screenLayer` (экранная, привязана к ракурсу)

- Фигуры в координатах 0…1 от viewport, валидны вместе с сохранённым `viewState`.
- При повороте камеры пользователем разметка **остаётся на экране**, геометрия «уезжает» — ожидаемое поведение.
- UX:
  - при отклонении камеры от сохранённого вида больше порога (например 8–10°) — **скрыть** `screenLayer`, оставить `anchor3d`;
  - кнопка **«Вернуть вид замечания»** в панели;
  - подсказка: «Разметка привязана к ракурсу».

Опционально позже: выноски в мировых координатах от `anchor3d` к подписи.

## Панель «Замечания»

- Отдельная панель (не смешивать с деревом Яндекс.Диска).
- Дерево: комментарии + ответы (`parentId`), фильтр по автору/статусу.
- Поле **description** — длинный текст только в панели (как eDrawings Description).
- Одно **активное** замечание; разметка остальных скрыта или приглушена.
- Инструменты: arrow, rect, ellipse, text, **image** (файл в assets).

## Порядок разработки

1. Схема JSON + загрузка/сохранение рядом с GLB; `remarksDirty`.
2. Панель-дерево + восстановление камеры по клику.
3. `anchor3d` — маркеры в `Viewer3D`.
4. `screenLayer` — оверлей (переиспользовать логику `ScreenshotEditorModal`).
5. Insert Image → `*_assets/`.
6. Поведение при отклонении камеры (скрытие screenLayer + «Вернуть вид»).
7. Модалка несохранённых изменений (общая с 3c).
8. Yjs / Диск (этапы 8, 5).

## Связь с PDF (3c)

| | PDF (3c) | 3D (3d) |
|--|----------|---------|
| Контекст | `pageNumber` | `viewState` + `anchor3d` |
| Слой | SVG 0…1 на странице | screenLayer 0…1 на viewport |
| Экспорт | PDF с выжженной разметкой | JSON + assets (GLB без изменений) |
| Просмотр | Страница PDF | **Живая** сцена |

Общая сущность **Comment** в коде — один тип, разные поля контекста.
