# PDF: оверлей замечаний и экспорт (этап 3c, 2026-05-19)

## Цель

Сохранять **исходный PDF** со всеми нарисованными на страницах стрелками, подписями и замечаниями — как в Figma: один человек или несколько. Не заменяет скриншоты в чат/отчёт, а даёт **полный документ** для согласования (в т.ч. 100+ листов).

## Текущее состояние кода

| Место | Что есть |
|-------|----------|
| `PdfViewer.vue` | Просмотр PDF.js (тайлы), без слоя разметки |
| `ScreenshotEditorModal.vue` | Рисование на **одном** изображении скриншота |
| `App.vue` (jspdf) | Отчёт из скриншотов + измерения, не «вшитая» разметка в исходный PDF |

## Этап 3c — порядок разработки (запланировано)

### 0. UI (этап 9)

- Левые табы PDF: **Документ** | **Замечания**; работа с деревом и вставкой картинок — из таба «Замечания».
- См. [session-2026-05-19-deskreview-ui-product.md](session-2026-05-19-deskreview-ui-product.md).

### 1. Оверлей

- Режим «Пометки» поверх `PdfViewer` (таб «Замечания»).
- Модель фигур: как в `ScreenshotEditorModal` (`arrow`, `rect`, `ellipse`, `text`), координаты **0…1** относительно страницы.
- Структура данных: `{ documentKey, pages: { "1": Shape[], "2": Shape[], ... } }`.
- IndexedDB: черновик по `documentKey`; `markupDirty = true` при изменениях.
- UI: панель инструментов, список замечаний по странице (позже — статусы из этапа 3).
- Производительность: оверлей только для видимой страницы / миниатюр с пометками.

### 2. Экспорт PDF

- Зависимость: **`pdf-lib`** (вектор поверх страниц исходного PDF).
- Обход всех страниц с непустой разметкой; прогресс в UI.
- **Два режима** (см. [session-2026-05-19-pdf-markup-removable-layer.md](session-2026-05-19-pdf-markup-removable-layer.md)):
  - **layered** — вложение `deskreview-markup.json`, чертёж без запекания;
  - **flattened** — пометки запечены в лист.
- Имена: `{basename}_с_замечаниями_…pdf` / `{basename}_замечания_запечённые_…pdf`.

### 3. Защита от потери

- Модалка при уходе (смена PDF, режима, закрытие проекта) если `markupDirty`.
- `window.beforeunload` — дополнительное стандартное предупреждение браузера.
- Периодический автосейв в IndexedDB (например, каждые 30 с).

### 4. Коллаборация (позже)

- Yjs / API: общий слой на документ (этап 8).
- Загрузка итогового PDF на Яндекс.Диск (этап 5).

## Имя файла при сохранении

```
{исходное_имя_без.pdf}_замечания_{дд.мм.гггг}_{чч-мм}.pdf
```

Пример: `Лист_ГП-01_замечания_19.05.2026_14-35.pdf`
