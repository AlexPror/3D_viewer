# PDF: снимаемый слой замечаний (2026-05-19)

## Задача

После сохранения нужно **снимать пометки** (видеть чистый чертёж) и **снова редактировать**, а не только запечённый вариант.

## Два режима экспорта

| Режим | Кнопка / Ctrl+S | Файлы | Снять пометки |
|--------|-----------------|-------|----------------|
| **layered** (по умолчанию) | «PDF + слой» | `{имя}_с_замечаниями_….pdf` + `{то же}.deskreview-markup.json` | Да: PDF без рисунков; слой в JSON |
| **flattened** | «Запечь» | `{имя}_замечания_запечённые_….pdf` | Нет — графика в странице |

## Файл слоя `.deskreview-markup.json`

```json
{
  "formatVersion": 1,
  "producer": "DeskReview",
  "markup": { "documentKey": "...", "pages": { "1": [ … ] } },
  "style": { "strokeRel", "arrowRel", "fontRel" },
  "savedAt": "ISO-8601"
}
```

- Скачивается **вместе** с PDF при «PDF + слой».
- Храните оба файла в одной папке.
- Повторное открытие: PDF + `.deskreview-markup.json` в одном перетаскивании или в диалоге «Открыть PDF» (можно выделить оба файла); иначе черновик из IndexedDB по имени PDF.
- Имя JSON: `{исходное_имя}.deskreview-markup.json` (не по имени экспортированного PDF с датой).

## В просмотрщике

- **«Пометки вкл / выкл»** — скрыть оверлей; чертёж без стрелок/текста на экране.
- Слой подгружается автоматически (см. выше); отдельной кнопки нет.

## Ограничения

- Acrobat **не** даёт галочку «слой замечаний» — снятие в DeskReview или правка JSON.
- Режим «Запечь» — как раньше, для отправки «как картинка на листе».
