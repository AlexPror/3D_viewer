# 3D Viewer — приложение

Вьюер 3D-моделей: STEP, STL, IGES, GLB. Часть проекта [DeskReview / 3D_viewer](../README.md).

**Версия:** 1.11.0 (см. `package.json`).

## Запуск

```bash
npm install
npm run dev
```

Или из корня репозитория: `run.bat` (сервер + фронт, Windows).

## Реализовано (v1.11.0)

- **Форматы:** STL, STEP/STP, IGES, GLB/GLTF — серверная конвертация STEP→GLB или WASM (opencascade.js, XCAF: дерево и цвета).
- **STL:** разбиение по связным телам, `meta.json`, авто-раскраска сегментов.
- **Сборка:** до 8 моделей в сцене, сопряжения по плоскостям, библиотека загруженных моделей.
- **Дерево деталей:** группы по именам; клик и **CAD-рамка** (window/crossing); **Esc** — сброс; яркая подсветка; двойной клик — изоляция.
- **Разнесение:** % от max габарита, якорь — крупнейшая деталь; измерения с привязкой к деталям при explode.
- **Каркас:** линии контура по всей сцене (кнопка «Каркас»).
- **ПКМ:** скрыть/показать, прозрачность; **вращение вокруг точки на детали** (при перетаскивании).
- **Измерения:** расстояние (прямое, live), cad-linear (вынос, drag, подсветка граней), радиус, сечение; журнал в боковой панели.
- **Скриншот-отчёт:** галерея «Все скриншоты», счётчик в шапке, анимация добавления.
- **Память:** dispose при удалении модели и unmount; очистка временных файлов WASM после STEP.
