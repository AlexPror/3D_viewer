# 3D Viewer — приложение

Вьюер 3D-моделей: STEP, STL, IGES, GLB. Часть проекта [DeskReview / 3D_viewer](../README.md).

**Версия:** 1.9.0 (см. `package.json`).

## Запуск

```bash
npm install
npm run dev
```

Или из корня репозитория: `run.bat` (сервер + фронт, Windows).

## Реализовано (v1.9.0)

- **Форматы:** STL, STEP/STP, IGES, GLB/GLTF — серверная конвертация STEP→GLB или WASM (opencascade.js).
- **Сборка:** до 8 моделей в сцене, сопряжения по плоскостям, библиотека загруженных моделей.
- **Дерево деталей:** группы по именам; выделение; двойной клик — изоляция детали в цвете.
- **Каркас:** линии контура по всей сцене (кнопка «Каркас»).
- **ПКМ:** скрыть/показать деталь, прозрачность, закрепить модель.
- **Измерения:** distance, cad-linear, радиус, сечение; журнал измерений.
- **Память:** dispose при удалении модели и unmount; очистка временных файлов WASM после STEP.

## Сборка

```bash
npm run build
```

Результат: `dist/`.
